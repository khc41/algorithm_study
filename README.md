# algorithm_study
Consistent algorithm problem-solving practice across multiple platforms.

## 📌 Goal
- Build problem-solving skill through consistent practice on Baekjoon (BOJ), LeetCode, Programmers, Codility, and SWEA.
- Organize solutions by algorithm/data-structure category so patterns are easy to review and reuse later.

## 📚 Platforms

### 🟦 [Baekjoon (BOJ)](./backjoon)
Organized by algorithm type: DP · Implementation · Graph · Exhaustive Search · Samsung SW Category · Greedy · I/O · Divide & Conquer · Binary Search · Bisection · Two Pointer · Dijkstra · Kruskal · Segment Tree · Prefix Sum · Past Contests

### 🟩 [Programmers](./programmers)
Coding test practice problems, including a dedicated [Kakao coding test archive](./programmers/kakao)

### 🟧 [LeetCode](./leetcode)
Solutions named after each problem's slug

### 🟨 [SWEA](./swea)
Samsung SW Expert Academy problems

### 🟪 [Codility](./codility)
Codility practice problems

## 🛠️ Languages
Java · C++ · Kotlin (new solutions are written in Kotlin)

## Claude Code Skills
- `/solve <problem-url>` - Detect the platform from a problem URL and scaffold a solution file in the correct directory (you write the code yourself)
- `/push <commit-message>` - Commit changed solution files and push to the remote branch
